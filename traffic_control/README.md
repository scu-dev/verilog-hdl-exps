# 交通信号灯控制器

顶层模块 `sig_control(hwy, cntry, X, clock, clear)` 采用《第7章·行为级建模》7.9 节的五状态控制器。主干道默认通行，乡村公路有车时请求切换。两路灯色均用两位编码表示，红灯为 `00`，黄灯为 `01`，绿灯为 `10`。

| 状态 | 主干道 hwy | 乡村公路 cntry | 转移条件 |
| --- | --- | --- | --- |
| S0 | 绿 | 红 | X=0 时保持，X=1 时转 S1 |
| S1 | 黄 | 红 | 3 秒后转 S2 |
| S2 | 红 | 红 | 2 秒后转 S3 |
| S3 | 红 | 绿 | X=1 时保持，X=0 时转 S4 |
| S4 | 红 | 黄 | 3 秒后转 S0 |

课件给出的等待长度依次为 3、2、3 个时钟周期。为了在 Basys3 上观察灯色，本工程用 100 MHz 时钟计数，把每个等待单位取为 1 秒。

## Basys3 接线

| 信号 | 板上器件 | 引脚 |
| --- | --- | --- |
| clock | 100 MHz 晶振 | W5 |
| clear | SW0 | V17 |
| X | SW1 | V16 |
| hwy[1:0] | LD1、LD0 | E19、U16 |
| cntry[1:0] | LD3、LD2 | V19、U19 |

`clear` 为高电平同步复位，`X` 经两级寄存器同步后进入状态机。每组 LED 中，全灭表示红灯，低位亮表示黄灯，高位亮表示绿灯。

## 上板操作

1. 将 SW1 置 0，把 SW0 拨到 1 再拨回 0。此时主干道绿灯，LD1 亮。
2. 将 SW1 拨到 1。LD0 亮 3 秒，随后四盏灯全灭 2 秒，再转为乡村公路绿灯，LD3 亮。
3. 保持 SW1 为 1，LD3 持续亮。将 SW1 拨回 0，LD2 亮 3 秒，然后回到主干道绿灯，LD1 亮。
