# 0–255 计数器

对应实验手册印刷页 26（PDF 第 27 页）“第 1 部分 0-255 计数器的实现”。

## 电路

`counter.v` 包含两个计数过程：

1. `div_count` 在 100 MHz 时钟下从 0 计到 99,999,999，每满一轮产生一个寄存器输出脉冲 `clk_1hz`。
2. 八位计数值 `B` 在 `clk_1hz` 的上升沿加 1，255 的下一次计数回到 0。

默认 `DIVISOR = 100_000_000`，所以分频周期为 100,000,000 × 10 ns = 1 s。脉冲高电平持续一个输入时钟周期（10 ns）；它是 1 Hz 脉冲，不是 50% 占空比方波，与手册前一节的寄存器脉冲分频示例一致。复位释放后，经过 100,000,000 个输入时钟上升沿才发生第一次加 1。

SW0 连接 `rst_n`。采用手册前一节示例的低电平有效异步复位：SW0=0 时两个计数器和分频输出清零，SW0=1 时开始计数。上电后先将 SW0 置 0，再置 1。

## 引脚

| 信号 | 板上器件 | FPGA 引脚 |
| --- | --- | --- |
| clk | 100 MHz 时钟 | W5 |
| rst_n | SW0 | V17 |
| B[7] | LD7 | V14 |
| B[6] | LD6 | U14 |
| B[5] | LD5 | U15 |
| B[4] | LD4 | W18 |
| B[3] | LD3 | V19 |
| B[2] | LD2 | U19 |
| B[1] | LD1 | E19 |
| B[0] | LD0 | U16 |

所有端口使用 LVCMOS33。XDC 同时声明 100 MHz 输入时钟及周期 1 s、高电平 10 ns 的派生时钟；派生时钟约束对应上板默认分频参数。

引脚已与 [Digilent Basys 3 官方约束](https://github.com/Digilent/digilent-xdc/blob/master/Basys-3-Master.xdc) 核对。

## 功能仿真

测试顶层为 `tb_counter`，只声明 clk、rst_n、B 和供波形观察的 clk_1hz，没有预期值、循环计数或错误计数辅助变量。

为了快速观察完整回绕，测试实例将 `DIVISOR` 覆盖为 10；硬件顶层默认值保持 100,000,000。输入时钟仍为 100 MHz，此时分频信号的仿真周期为 100 ns，并不把该加速波形称为真实 1 Hz。

打开 counter.xpr，选择 Run Behavioral Simulation。仿真运行时长设为 30 us；测试在 26.22 us 自动结束。将 B 显示为无符号十进制，观察：

- 0–20 ns：复位，B=0，clk_1hz=0。
- 115 ns：第一次计数，B=1；之后每 100 ns 加 1。
- 25.515 us：B=255。
- 25.615 us：B 回到 0。
- 25.852 us：在非时钟边沿再次复位，B 从 2 立即清零。
- 25.870 us：释放复位，25.965 us 重新计到 1。

2026-09-22 使用 Vivado 2015.2 XSim 对最终代码进行了仿真，并在测试文件之外逐时间点检查导出的 VCD 波形：261 次加 1、完整回绕、异步复位、复位后的重新分频均通过；分频上升沿间隔 100 ns，高电平宽度 10 ns。

另以默认参数完成单模块综合和时钟约束检查：36 个触发器、0 个锁存器，派生时钟周期为 1,000,000,000 ns。综合过程报告 0 errors、0 critical warnings、0 warnings。旧版工具启动时的 Tcl Store 目录报错及 WebTalk 遥测报错没有阻止这些检查完成。

本次没有按默认参数仿真完整 256 s，没有运行布局布线、生成比特流或进行实验板下载。

## 实验板操作

需要上板时，在 Vivado 中完成实现和 Generate Bitstream，然后通过 Hardware Manager 下载生成的 counter.bit。先让 SW0=0 复位，再置 1：LD7～LD0 应从 00000000 开始，每秒增加 1，到 11111111 后下一秒回到 00000000。再次将 SW0 置 0，应立即清零。

如果工程在添加文件前已经打开，请重新打开 counter.xpr，使新增源文件、仿真顶层和约束生效。
